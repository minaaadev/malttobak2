# 말또박 2 — 마비말장애 재활훈련 PWA

성인 마비말장애 사용자의 **자가 반복 연습을 보조**하기 위한 설치형 웹앱(PWA) 프로토타입입니다. 진단, 의료기기, 치료 효과 판정용 소프트웨어가 아닙니다.

## 2차 버전 기능
- 맞춤형 일일 훈련 계획: 호흡·발성 / 조음 / 말속도·운율 / 생활 문장 영역 선택
- 짧게 / 기본 / 충분히 훈련량 설정
- 호흡-발성 협응 및 편안한 모음 지속 연습
- 발성 지속시간 수동 타이머(참고 기록, 정상치 판정 없음)
- 말속도 훈련용 50~80 BPM 메트로놈
- 한국어 TTS 예시 음성 및 예시 속도 조절
- 사용자 음성 녹음/재생 + 마이크 입력 시각화
- 지원 브라우저에서 참고용 한국어 받아쓰기(발음 점수 아님)
- 과제별 체감 난이도와 피로 체크
- 사용자/보호자/재활사가 직접 생활 문장 최대 12개 추가
- 빠른 의사소통(AAC 보조) 카드와 음성 출력
- 최근 7일 훈련 요약 및 기기 내 기록
- 훈련 기록 CSV 내보내기
- 큰 글씨 / 단순 훈련 화면
- PWA 설치 및 오프라인 캐시

## 실행
마이크 기능은 보안 컨텍스트(HTTPS 또는 localhost)가 필요합니다.

```bash
cd malttobak_v2
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

같은 Wi-Fi의 스마트폰에서 PC의 IP로 접속할 경우 HTTP에서는 마이크가 제한될 수 있으므로 실제 배포는 HTTPS를 권장합니다.

## 데이터
- 모든 설정과 훈련 기록은 기본적으로 브라우저 `localStorage`에만 저장됩니다.
- 음성 녹음은 서버에 업로드하지 않으며 현재 세션에서 재생하기 위한 브라우저 객체 URL로만 사용됩니다.
- CSV 내보내기는 사용자가 직접 실행합니다.

## 임상/제품화 시 필요한 추가 단계
1. 언어재활사와 환자군별 목표·금기·과제 강도 검토
2. 실제 대상 사용자 사용성 평가 및 접근성 테스트
3. 개인정보 처리방침, 동의 흐름, 데이터 보안 설계
4. 의료기기 해당 여부 및 적용 규제 검토
5. 음성 기능의 기기/브라우저별 성능 검증
6. 효과를 주장하려면 별도의 임상적 검증 및 적절한 연구 설계

## 설계 원칙
마비말장애 치료는 원인, 중증도, 동반 장애, 영향을 받은 말 산출 체계에 따라 개인화되어야 합니다. 이 앱은 고정된 치료법을 처방하지 않고 영역 선택, 실제 생활 문장, 피로에 따른 중단, 보조 의사소통을 지원하는 구조로 설계했습니다.
